## Asistentes de IA generales

- [ChatGPT](https://chatgpt.com) 🟢 - El asistente más conocido. Redacción, análisis de datos, imágenes y GPTs personalizados.
- [Claude](https://claude.ai) 🟢 - Destaca en redacción natural, análisis de documentos largos y Proyectos con el contexto de tu negocio.
- [Gemini](https://gemini.google.com) 🟢 - El asistente de Google, integrado con Gmail, Docs y Drive. Permite crear Gems personalizados.
- [Microsoft Copilot](https://copilot.microsoft.com) 🟢 - Integrado en Windows y en Microsoft 365 (Word, Excel, Outlook, Teams).
- [Le Chat de Mistral](https://chat.mistral.ai) 🟢 🇪🇺 - Alternativa europea, interesante para empresas que priorizan la soberanía de datos.

## Investigación y documentos

- [Perplexity](https://www.perplexity.ai) 🟢 - Buscador con IA que cita sus fuentes. Ideal para estudiar mercado y competencia.
- [NotebookLM](https://notebooklm.google.com) 🟢 - Sube tus documentos y conversa con ellos. Genera resúmenes y resúmenes en audio.

- [Canva](https://www.canva.com) 🟢 - Diseño de posts, carruseles y presentaciones con funciones de IA integradas.

## Privacidad y RGPD

Antes de usar cualquier herramienta con datos de tu empresa:

1. **Revisa dónde se guardan los datos** y si la herramienta los usa para entrenar sus modelos.
2. **Usa planes de empresa** cuando trabajes con datos de clientes: suelen incluir mejores garantías de privacidad.
3. **No pegues datos personales** de clientes o empleados en versiones gratuitas.
4. **Firma un contrato de encargo de tratamiento** con el proveedor si trata datos personales por tu cuenta.
5. **Informa a tu equipo** de qué herramientas se pueden usar y con qué datos.

## Cómo contribuir

¿Conoces una herramienta útil para pymes que no está en la lista? ¡Las contribuciones son bienvenidas!

1. Haz un fork del repositorio.
2. Añade la herramienta en la categoría correcta con este formato: nombre con enlace, icono de plan y una frase sobre para qué sirve a una pyme.
3. Abre un pull request explicando por qué es útil.

Solo se aceptan herramientas activas, útiles para pymes sin perfil técnico y sin enlaces de afiliado.
